# 🧮 Simple Calculator

A beginner-friendly Python calculator that performs basic arithmetic operations and calculates the average of two numbers.

## 📋 Features

✨ **Addition** - Add two numbers  
✨ **Subtraction** - Subtract two numbers  
✨ **Multiplication** - Multiply two numbers  
✨ **Division** - Divide two numbers (with zero-check)  
✨ **Average** - Calculate average of two numbers  
✨ **Input Validation** - Handles invalid inputs gracefully  
✨ **Error Handling** - Prevents division by zero  

## 💻 Tech Stack

- **Language:** Python 3
- **Concepts:** Functions, Conditionals, Input/Output, Error Handling

## 🚀 How to Run

### Prerequisites
- Python 3.x installed on your system

### Steps
1. **Clone or download the repository**
   ```bash
   git clone https://github.com/ravikumawat/calculator.git
   cd calculator
   ```

2. **Run the calculator**
   ```bash
   python calculator.py
   ```

3. **Follow the prompts**
   - Select an operation (1-5)
   - Enter two numbers
   - View the result
